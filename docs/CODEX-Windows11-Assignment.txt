PROJECT: Implement a Windows 11-Inspired Desktop for WovenHat-OS

OVERVIEW:
Build a modern Windows 11-style desktop with a bottom taskbar, app launcher,
and integrated system management. Key features:
- Bottom taskbar (50px) with pinned/running apps
- Start Menu app launcher (Super key)
- App Switcher with window previews (Alt+Tab)
- System tray (clock, battery, volume, WiFi, settings)
- Notifications (toasts + action center)
- Window snap layouts
- Settings integration
- Theme system (light/dark modes)

CRITICAL DESIGN REQUIREMENT:
✓ TASKBAR AT BOTTOM (like Windows 11)
✗ NO top bar
✗ NO GNOME Activities overlay
✗ NO workspace preview

DELIVERABLES:
1. wovenhat-windows-shell (main desktop shell)
   - 8 modules for all desktop features
   
2. wovenhat-settings-daemon (background service)
   - System settings management
   
3. wovenhat-action-center (notification hub)
   - Notification history and Do Not Disturb
