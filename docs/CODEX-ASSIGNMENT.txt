PROJECT: Implement a GNOME-Inspired Desktop Environment for WovenHat-OS

OVERVIEW:
Build a complete, modern desktop shell that integrates with the existing 
WovenShell window manager and kernel graphics subsystem. This will include:
- Activities overview (app launcher + window switcher)
- Top bar (system panel with clock, status, power menu)  
- Notifications system (toasts + notification center)
- App launcher with search and categories
- Window management (snap, maximize, Alt+Tab, workspaces)
- Settings integration (display, audio, network, power)
- Keyboard shortcuts and themes

DELIVERABLES:
1. wovenhat-gnome-shell (main desktop shell service)
   - 8-10 modules for all desktop features
   
2. wovenhat-settings-daemon (background service)
   - System settings management
   
3. wovenhat-notifications (notification service)
   - Notification queue and persistence
